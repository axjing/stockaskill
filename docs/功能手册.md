# stockaskill 功能全景手册

> 版本: 1.5.0 | 更新日期: 2026-07-10

## 一、项目定位

stockaskill 是一个**本地优先的多因子量化选股与投资分析系统**，覆盖 A 股 / 港股 / 美股 / ETF 四大市场，提供从选股、诊断、组合构建、回测到持仓跟踪的完整投资决策链路。

核心设计理念：
- **本地优先** — 所有数据缓存到 SQLite，API 仅用于增量同步
- **按任务补数据** — 只拉当前任务必需的数据，不做全市场全量重拉
- **7+1 因子模型** — 估值 / 质量 / 成长 / 动量 / 低波 / 市值 / 情绪 + 综合评分

## 三、核心功能一览

### 3.1 个股分析

| 命令 | 功能 | 适用场景 |
|------|------|---------|
| `analyze` | 个股综合分析（多因子 + 策略评分） | 快速了解一只股票 |
| `diagnose` | 深度个股诊断 | 建仓前深度研究 |
| `deep-diagnose` | 长报告版诊断，含详细逻辑 | 复盘归档 |
| `scorecard diagnose` | 对个股诊断报告做结构化评分卡 | 横向对比多只标的 |

```bash
python skills/stockaskill/scripts/run.py analyze 600519 --market A
python skills/stockaskill/scripts/run.py diagnose 600519 --market A
python skills/stockaskill/scripts/run.py deep-diagnose 600519 --market A --format both
python skills/stockaskill/scripts/run.py scorecard diagnose 600519 --market A
```

### 3.2 全市场扫描 / 选股

| 命令 | 功能 | 模式 |
|------|------|------|
| `scan` | 全市场多因子评分排名 | `auto`（优先快照，缺失时回退实时）/ `snapshot` / `realtime` |
| `refresh-scan` | 构建全市场快照并输出排名 | — |
| `alpha` | Alpha 动量策略扫描 | — |

```bash
python skills/stockaskill/scripts/run.py scan A --top 20
python skills/stockaskill/scripts/run.py scan A --mode realtime --top 20
python skills/stockaskill/scripts/run.py refresh-scan A --top 20
python skills/stockaskill/scripts/run.py alpha A --top 10
```

**扫描模式说明：**
- `auto`（默认）：本地快照新鲜时直接读取；过期或缺失时自动回退到有界实时扫描
- `snapshot`：仅读取本地全市场快照
- `realtime`：对有界候选池做实时评分

### 3.3 组合构建

| 命令 | 功能 |
|------|------|
| `portfolio` | 均值-方差优化组合（传统策略） |
| `portfolio-enhanced` | ETF(3) + Alpha Momentum Top3 = 6 仓位的增强组合 |

```bash
python skills/stockaskill/scripts/run.py portfolio --codes 600519,000858 --capital 1000000
python skills/stockaskill/scripts/run.py portfolio-enhanced --capital 1000000
```

组合约束：
- 单只权重上限 20%
- 持仓数量 6-30 只
- 再平衡频率 30 天

三种风险偏好：保守型（预期回撤 ≤10%）/ 稳健型（≤15%）/ 进取型（≤25%）

### 3.4 回测验证

| 命令 | 功能 |
|------|------|
| `backtest` | Alpha 动量策略回测（2018-2026） |
| `backtest-enhanced` | 增强 Core-Satellite 策略回测 |

```bash
python skills/stockaskill/scripts/run.py backtest
python skills/stockaskill/scripts/run.py backtest --market HK
python skills/stockaskill/scripts/run.py backtest-enhanced
```

输出指标：总收益 / 年化收益 / 最大回撤 / 夏普比率 / 卡玛比率 / 胜率 / 净值曲线

### 3.9 数据管理

#### 有界同步（推荐方式）

不再"先全量拉完再分析"，改为按任务范围同步：

| 命令 | 功能 |
|------|------|
| `sync symbol` | 同步单只股票 |
| `sync watchlist` | 同步关注列表 |
| `sync portfolio` | 同步组合成分股 |
| `sync scan-universe` | 同步扫描候选池 |
| `sync etf` | 同步 ETF 数据 |

```bash
python skills/stockaskill/scripts/run.py sync symbol 600519 --market A
python skills/stockaskill/scripts/run.py sync watchlist --market HK
python skills/stockaskill/scripts/run.py sync portfolio --codes AAPL,MSFT --market US
python skills/stockaskill/scripts/run.py sync scan-universe --market A --limit 200
python skills/stockaskill/scripts/run.py sync etf --codes 510300,159915
```

#### 数据状态诊断

```bash
python skills/stockaskill/scripts/run.py status data symbol 600519 --market A
python skills/stockaskill/scripts/run.py status data watchlist --market US
python skills/stockaskill/scripts/run.py status data pool --market A
```

#### 传统拉取方式（保留兼容）


```bash

```

## 四、因子体系

系统使用 7 大因子 + 综合评分：

| 因子 | 权重 | 说明 |
|------|:----:|------|
| 估值因子 | 20% | PE/PB/股息率复合估值 |
| 质量因子 | 25% | ROE/毛利率/负债率/FCF 质量 |
| 成长因子 | 17% | 营收/净利润同比增长 |
| 动量因子 | 17% | 6 月动量（剔除近 1 月反转） |
| 低波因子 | 11% | 12 月日波动率 |
| 市值因子 | 9% | log(总市值) 负向打分 |

**增强版权重**（Core-Satellite）：动量 35% / 低波 18% / 质量 20% / 估值 17% / 成长 10%

## 五、数据架构

```
┌─────────────┐    ┌──────────────────┐    ┌─────────────┐
│  用户命令    │───▶│  本地 SQLite DB  │───▶│  API 增量   │
│  CLI/Agent  │    │  quant_cache.db   │    │  同步 (按需) │
└─────────────┘    └──────────────────┘    └─────────────┘
                          │
                    ┌─────┴─────┐
                    │  数据表    │
                    ├───────────┤
                    │stock_pool │  股票池 + 元数据质量
                    │daily_price│  日 K 线
                    │factor_    │  基本面快照
                    │snapshot   │
                    │computed_  │  计算因子值
                    │factors    │
                    │sentiment  │  情绪分析
                    │sync_state │  同步状态
                    │cache_meta │  缓存元信息
                    │api_usage  │  API 配额
                    └───────────┘
```

**关键原则：**
- SQLite 是唯一查询层，远端 API 仅作同步
- 增量补全，永远只拉缺失区间（带 3 天重叠修正）
- 多源容错：K 线 AKShare → baostock → efinance → yfinance；基本面 THS → Sina → yfinance
- 连续失败源自动退避，日配额默认 500 次

## 八、Python API 使用

```python
import sys
from pathlib import Path
sys.path.insert(0, str(Path(__file__).resolve().parent / "stockaskill" / "scripts"))

from advisor.diagnosis import StockDiagnosis
from factors.composite import CompositeAnalyzer
from strategies.aggregator import StrategyAggregator
from portfolio.builder import PortfolioBuilder
from data_engine import get_stock_pool, get_kline

# 1. 获取股票池
pool = get_stock_pool(market="A")

# 2. 个股深度分析
diagnosis = StockDiagnosis("600519", "A").full_report()

# 3. 量化策略综合评分
strategies = StrategyAggregator("600519", "A").analyze_all()

# 4. 多因子分析
factors = CompositeAnalyzer("600519", "A").analyze()

# 5. 构建组合
builder = PortfolioBuilder("我的组合", capital=1000000)
builder.add_from_strategy("600519", "A")
portfolio = builder.build()
print(portfolio.summary())
```

## 九、输出报告

所有分析命令默认输出到 `reports/` 目录，支持三种格式：

- `--format json` — 结构化 JSON，适合程序消费
- `--format md` — 可读 Markdown 报告
- `--format both`（默认） — 同时生成两种格式

## 十、风险提示

- 本工具输出仅作为投资参考，不构成投资建议
- 所有数据来自第三方公开平台，存在 0-15 分钟延迟
- 历史回测结果不代表未来收益
- 投资有风险，入市需谨慎
